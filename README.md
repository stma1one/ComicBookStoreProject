## 📚 חלק א': דף עזר ומילון מתודות (Cheat Sheet)

### 1. עבודה עם `List<T>` (רשימה דינמית)
רשימה היא אוסף מסודר של איברים מאותו סוג, שגודלה משתנה באופן דינמי.

| מתודה / מאפיין | תיאור | דוגמת שימוש בקוד C# |
| :--- | :--- | :--- |
| **יצירת רשימה** | יצירת מופע חדש של רשימה | `List<ComicBook> books = new List<ComicBook>();` |
| **`Add(item)`** | הוספת איבר לסוף הרשימה | `books.Add(new ComicBook("X-Men #1", 1991, "X-Men", 8));` |
| **`Count`** | החזרת מספר האיברים ברשימה | `int total = books.Count;` |
| **גישה לפי אינדקס** | גישה/עדכון איבר במיקום מסוים | `ComicBook first = books[0];` |
| **`Remove(item)`** | הסרת האיבר הראשון התואם | `books.Remove(comicObj);` |
| **`RemoveAt(index)`** | הסרת איבר לפי אינדקס | `books.RemoveAt(2); // מסיר את האיבר באינדקס 2` |
| **`Contains(item)`** | בדיקה אם איבר קיים ברשימה | `bool exists = books.Contains(comicObj);` |
| **`Clear()`** | מחיקת כל האיברים מהרשימה | `books.Clear();` |
| **סריקה בבלולאת `foreach`** | מעבר על כל איברי הרשימה | <pre>foreach (ComicBook b in books)<br>{
    Console.WriteLine(b.Title);
}</pre> |

---

### 2. עבודה עם `Dictionary<TKey, TValue>` (מילון מפתח-ערך)
מילון הוא אוסף של זוגות של **מפתח** (Key) ו**ערך** (Value). המפתחות חייבים להיות ייחודיים!

| מתודה / מאפיין | תיאור | דוגמת שימוש בקוד C# |
| :--- | :--- | :--- |
| **יצירת מילון** | יצירת מילון שבו המפתח string והערך int | `Dictionary<string, int> stock = new Dictionary<string, int>();` |
| **`Add(key, value)`** | הוספת זוג חדש למילון (זורק שגיאה אם המפתח קיים) | `stock.Add("Spider-Man #300", 5);` |
| **אינדקסר `[key]`** | הוספה או עדכון ערך לפי מפתח | `stock["Spider-Man #300"] = 10; // מעדכן ל-10 או מוסיף אם לא קיים` |
| **`ContainsKey(key)`** | בדיקה אם מפתח קיים במילון (מחזיר `bool`) | `if (stock.ContainsKey("Batman")) { ... }` |
| **`ContainsValue(value)`** | בדיקה אם ערך קיים במילון | `bool hasZero = stock.ContainsValue(0);` |
| **`TryGetValue(key, out value)`** | שליפת ערך בצורה בטוחה ללא שגיאה | <pre>if (stock.TryGetValue("Batman", out int count))<br>{
    Console.WriteLine($"Found: {count}");
}</pre> |
| **`Remove(key)`** | הסרת מפתח והערך שלו מהמילון | `stock.Remove("Spider-Man #300");` |
| **`Count`** | החזרת מספר הזוגות במילון | `int uniqueTitles = stock.Count;` |
| **`Keys` / `Values`** | גישה לאוסף המפתחות או ה ערכים בלבד | `foreach (string title in stock.Keys) { ... }` |
| **סריקה בבלולאת `foreach`** | מעבר על כל הזוגות במילון | <pre>foreach (KeyValuePair<string, int> pair in stock)<br>{
    Console.WriteLine($"{pair.Key} -> {pair.Value}");
}</pre> |

## 🛠️ חלק ב': תיאור הפרויקט והמחלקות

בפרויקט קיימות שתי מחלקות מרכזיות:

2. **`ComicStore`**: מחלקת החנות המכילה רשימת חוברות (`List<ComicBook> Inventory`). בפעולה הבונה שלה מוזנות מראש **20 חוברות קומיקס** שונות (כולל חוברות שהמלאי שלהן הוא 0).

## 📝 חלק ג': המשימות לפתרון התלמידים

עליכם לממש את הפעולות הבאות במחלקה `ComicStore.cs`:

### משימה 1: `AddOrUpdateComic(ComicBook newComic)`
- **תיאור**: הפעולה מקבלת עצם של חוברת קומיקס.
- **דרישה**: יש לבדוק האם חוברת בעלת **אותו שם** (`Title`) כבר קיימת ברשימת `Inventory`.
  - אם היא קיימת - יש להגדיל את הכמות במלאי (`StockQuantity`) של החוברת הקיימת בכמות של החוברת החדשה.
  - אם היא אינה קיימת - יש להוסיף את החוברת החדשה ל-`Inventory`.

---

### משימה 2: `UpdateStock(string title, int newQuantity)`
- **תיאור**: הפעולה מקבלת שם חוברת קומיקס וכמות חדשה למלאי.
- **דרישה**: יש לחפש את החוברת ברשימה לפי השם. אם נמצאה - יש לעדכן את הכמות במלאי ל-`newQuantity` ולהחזיר `true`. אם החוברת לא נמצאה - יש להחזיר `false`.

---

### משימה 3: `SearchByHero(string heroName)`
- **תיאור**: הפעולה מקבלת שם של גיבור (למשל `"Batman"`).
- **דרישה**: הפעולה מחזירה רשימה חדשה (`List<ComicBook>`) הכוללת את כל החוברות של אותו גיבור שנמצאות בחנות.

---

### משימה 4: `IsInStock(string title)`
- **תיאור**: הפעולה מקבלת שם חוברת.
- **דרישה**: יש להחזיר `true` אך ורק אם החוברת קיימת בחנות **ומהכמות במלאי שלה גדולה מ-0**. בכל מקרה אחר יש להחזיר `false`.

---

### משימה 5: `GetStockDictionary()`
- **תיאור**: הפעולה אינה מקבלת פרמטרים.
- **דרישה**: עליכם ליצור ולהחזיר מילון (`Dictionary<string, int>`), שבו:
  - **המפתח (Key)**: שם חוברת הקומיקס (`Title`).
  - **הערך (Value)**: הכמות שלה במלאי (`StockQuantity`).

---

### משימה 6: `GetQuantityFromDictionary(string title)`
- **תיאור**: הפעולה מקבלת שם חוברת.
- **דרישה חובה**: בתוך הפעולה יש לזמן קודם כל את הפעולה `GetStockDictionary()` שמימשתם בסעיף 5!
- לאחר מכן, יש לחפש במילון המתקבל את שם החוברת:
  - אם החוברת קיימת במילון - החזירו את הכמות שלה.
  - אם החוברת אינה קיימת במילון - החזירו `-1`.

---

### משימה 7 (אתגר בונוס): `GetHeroWithMostComics()`
- **תיאור**: הפעולה מחזירה את שם הגיבור שיש לו הכי הרבה חוברות קומיקס בחנות (מספר חוברות שונות ברשימה, ללא קשר לכמות המלאי).
- **רמז**: מומלץ להיעזר במילון עזר שסופר כמה חוברות קיימות לכל גיבור!
